### 1. 自动存档 FIFO 3 槽位
**来源**：姬侠传 `storage-service.js`  
**价值**：高 | **难度**：低 | **优先级**：⭐⭐⭐

**当前问题**：
- `localStorage['calamity-game-state']` 只有一份存档
- 玩家想回滚到 5 分钟前很麻烦
- 没有版本对比功能

**实施方案**：
```javascript
// 改造 storage-service.js
var SAVE_SLOTS = ['slot1', 'slot2', 'slot3'];

function saveToSlot(slotName, gameData) {
  localStorage.setItem('calamity-save-' + slotName, JSON.stringify({
    data: gameData,
    timestamp: Date.now(),
    name: '' // 可选玩家命名
  }));
}

function loadFromSlot(slotName) {
  return JSON.parse(localStorage.getItem('calamity-save-' + slotName) || 'null');
}

function autoSave(gameData) {
  // 找到最旧的 slot 覆盖
  var oldest = findOldestSlot();
  saveToSlot(oldest, gameData);
}
```

**接入点**：
- 玩家每次发送消息前自动保存
- UI 增加"存档管理"按钮（查看/加载/删除）
- 显示存档时间戳和游戏进度

### 2. variable-system.js 接入使用
**来源**：姬侠传 `variable-system.js`（同名）  
**价值**：高 | **难度**：中 | **优先级**：⭐⭐⭐

**当前问题**：
- `module/variable-system.js` 已实现完整功能
- 但**没有被实际使用**（grep 结果 0 处调用）
- 当前所有数据都堆在 `game-state.js` 一锅端

**目标**：
```
turn:    当前回合（重新生成时回滚）
session: 当前存档（跨回合持久）
global:  全局设置（跨存档持久）
```

**实施步骤**：

**步骤 1：初始化**
```javascript
// game-state.js 启动时
function initVariables(gameData) {
  variableSystem.init(gameData);
  // global 从 localStorage 读取
  var settings = JSON.parse(localStorage.getItem('calamity-global-settings') || '{}');
  Object.keys(settings).forEach(k => variableSystem.set(k, settings[k], 'global'));
}
```

**步骤 2：读写改造**
```javascript
// 原写法
function getState(key) {
  return gameData[key];
}

// 改造后
function getState(key) {
  var v = variableSystem.get(key);
  if (v !== undefined) return v;
  return gameData[key]; // 兜底
}
```

**步骤 3：回合管理**
```javascript
function beginTurn() { variableSystem.beginTurn(); }
function commitTurn() { variableSystem.commitTurn(); }
function rollbackTurn() { variableSystem.rollbackTurn(); }
```

**步骤 4：数据分级**
- `global` - 主题/语言/API 配置
- `session` - 角色/HP/装备/任务
- `turn` - 本回合临时状态/未提交伤害

**步骤 5：存档兼容迁移**
```javascript
function migrateToVariableSystem() {
  var legacy = JSON.parse(localStorage.getItem('calamity-game-state') || '{}');
  Object.keys(legacy).forEach(k => {
    if (k === 'settings') variableSystem.set(k, legacy[k], 'global');
    else variableSystem.set(k, legacy[k], 'session');
  });
}
```

**预计工作量**：8-12 小时

**风险提示**：
- 全量改造可能引入 bug
- 建议先在新功能试点

### 7. ST 预设导入器
**创建日期**：2026-09-03
**优先级**：待定
**状态**：✅ 已完成（2026-09-03，方案 A：接入 ST 宏）

- `module/prompt-builder.js`：marker 感知注入——
  - worldInfoBefore/worldInfoAfter marker → 注入游戏系统提示词（落在预设 `<WorldContext>` 等包装标签内；无 marker 时退回消息链首位）

  - assistant 角色 → 恒为消息链末尾预填充
- 启用优先级按 ST 语义：order 条目 enabled 为准（prompts 库 enabled 只是默认值，order 开/prompt 关时 order 赢）
- 实测「梁元·极昼 polarday 0.1.9」：宏 100% 覆盖、零残留；order 优先级修正恢复 矜持化/随机事 共 2003 字内容
- 验证脚本：`tools-test-preset-engine.js`（宏引擎回归）、`tools-test-preset-e2e.js`（全链路 17 项）、`tools-scan-preset-macros.js`（宏覆盖扫描）、`tools-check-enabled-conflict.js`（启用冲突诊断）

**核心功能**：
- 上传 ST 预设 JSON 文件（.json）
- 解析生成参数：temperature / top_p / max_tokens / frequency_penalty / presence_penalty
- 提取启用的 prompts 数组
- 解析 {{setvar::}} 变量宏
- 应用到 api-service.js + prompt-builder.js

**实施步骤**：
1. 新建 `module/preset-importer.js`

3. 提取参数 → 替换 api-service.js 的 generateConfig

6. UI 入口：设置面板加"导入 ST 预设"按钮
7. 保存到 localStorage['calamity-preset']
