## 📋 系统概述

### 核心职责
```
将游戏事件（战斗/检定/交互）转化为格式化的卡牌正文输出
符合《输出格式.yaml》规范
支持三种显示模式（原始/美化/隐藏）
```

### 为什么需要这个系统？
```
现状：
- ✅ 已有战斗计算引擎（combat-system）
- ✅ 已有检定计算引擎（check-system）
- ✅ 已有装备/生物数据
- ❌ 缺少格式化输出

问题：
- 计算结果是数据，不是正文
- 无法直接作为卡牌输出
- 需要转化为可读的叙事文本

解决：
- narrative-system 负责格式化输出
- 将计算结果转化为标准正文
- 生成符合规范的标签
```

### 3. 战斗标签生成

#### <battle> 标签格式
```
<battle>

====== 战斗开始 ======
先攻顺序：凛夏（16）→ 灰烬狼（12）
交战距离：10米

===== 第1回合 =====

■ 凛夏（HP：30/30 ｜ AC：14）
[ 攻击检定：d20(15) + 2 = 17 vs AC = 12 ]
命中
[ 伤害：8（斩击）]

■ 灰烬狼（HP：16/24 ｜ 威胁等级：中）
[ 攻击检定：d20(8) + 3 = 11 vs AC = 14 ]
未命中

===== 第2回合 =====
...

====== 战斗结束 ======
胜利！击败灰烬狼。

</battle>
```

#### 实现逻辑
```javascript
formatBattleTag(combat) {
  // 1. 战斗开始
  output += '====== 战斗开始 ======\n';
  output += `先攻顺序：${turnOrder}\n`;
  
  // 2. 按回合整理日志
  const logsByRound = {};
  combat.log.forEach(log => {
    logsByRound[log.round].push(log);
  });
  
  // 3. 输出每回合
  Object.keys(logsByRound).forEach(round => {
    output += `===== 第${round}回合 =====\n`;
    
    // 角色信息
    output += `■ ${name}（HP：${hp} ｜ AC：${ac}）\n`;
    
    // 攻击检定
    output += `[ 攻击检定：d20(...) vs AC = ... ]\n`;
    
    // 结果
    output += hit ? '命中\n' : '未命中\n';
    
    // 伤害
    if (hit) output += `[ 伤害：${damage} ]\n`;
  });
  
  // 4. 战斗结束
  output += '====== 战斗结束 ======\n';
  output += combat.status === 'victory' ? '胜利！' : '战败...';
  
  return '<battle>\n' + output + '\n</battle>';
}
```

### 4. 检定标签生成

#### <check> 标签格式
```
<check>
[ 感知检定：d20(18) + 1 + 2 = 21 vs DC = 15 ]
成功
</check>
```

#### 实现逻辑
```javascript
formatCheckTag(checkResult) {
  let output = '<check>\n';
  
  output += `[ ${checkResult.skillName}检定：`;
  output += `d20(${checkResult.roll})`;
  
  if (checkResult.modifier !== 0) {
    output += ` + ${checkResult.modifier}`;
  }
  
  if (checkResult.proficiencyBonus !== 0) {
    output += ` + ${checkResult.proficiencyBonus}`;
  }
  
  output += ` = ${checkResult.total}`;
  output += ` vs DC = ${checkResult.dc} ]\n`;
  
  if (checkResult.success) {
    output += `成功`;
    if (checkResult.criticalSuccess) output += `（大成功！）`;
  } else {
    output += `失败`;
    if (checkResult.criticalFailure) output += `（大失败！）`;
  }
  
  output += '\n</check>';
  return output;
}
```

## 🎨 显示模式

### 三种显示模式

#### 1. 原始格式（Raw）
```
特点：
- 纯文本显示
- 保留所有标签
- 适合复制到AI对话
- 可以看到原始格式

使用场景：
- 调试
- 复制到SillyTavern
- 检查格式正确性
```

#### 2. 美化格式（Beautified）⭐ 推荐
```
特点：
- 彩色边框
- 图标美化（⚔ ✨ 💰 💖 📚）
- 标签分类显示
- 战斗面板高亮
- 最佳阅读体验

CSS实现：
.tag-wrapper {
  margin: 10px 0;
  padding: 10px 15px;
  border-radius: 6px;
  border-left: 4px solid;
}

.tag-battle {
  background: rgba(255, 152, 0, 0.1);
  border-color: #ff9800;
}
```

#### 3. 隐藏标签（Hidden）
```
特点：
- 只显示叙事正文
- 隐藏所有标签
- 纯小说阅读体验

CSS实现：
.narrative-output.hide-tags .tag-wrapper {
  display: none;
}
```

## 📝 正文生成

### 战斗正文生成

```javascript
generateCombatNarrative(combat, narrativeIntro) {
  // 1. 叙事开场
  let narrative = narrativeIntro || generateCombatIntro(combat);
  
  // 2. 生成战斗标签
  const battleTag = formatBattleTag(combat);
  
  // 3. 生成结算标签
  const tags = {
    exp: formatExpTag(combat.rewards.exp, '击败敌人'),
    gold: formatGoldTag(combat.rewards.gold, '战利品', currentGold)
  };
  
  // 4. 组装完整输出
  return formatOutput({
    narrative: narrative + '\n' + battleTag,
    tags: tags
  });
}
```

### 战斗开场叙事（随机）
```javascript
generateCombatIntro(combat) {
  const enemies = combat.enemies.map(e => e.name).join('、');
  
  const intros = [
    `灰烬在你脚下腾起薄薄的烟尘。${enemies}从焦木后跃出，发出低沉的咆哮。`,
    `前方传来动静。${enemies}出现在视野中。`,
    `废墟的阴影中，${enemies}缓缓走出。`,
    `警戒！${enemies}发起攻击！`
  ];
  
  return intros[Math.floor(Math.random() * intros.length)];
}
```

## 🔧 API 使用示例

### 示例 1：生成战斗正文
```javascript
// 1. 创建战斗
const combat = combatSystem.startCombat(player, ['灰烬狼']);

// 2. 执行战斗
while (combat.status === 'active') {
  const actor = combatSystem.getCurrentActor(combat);
  if (actor.type === 'player') {
    combatSystem.playerAttack(combat, targetId, 'mainHand');
  }
}

// 3. 生成正文
const output = narrativeSystem.generateCombatNarrative(combat);

// 4. 显示
console.log(output);
```

### 示例 2：生成检定正文
```javascript
// 1. 执行检定
const checkResult = checkSystem.performCheck({
  skillName: '感知',
  attributes: attributes,
  dc: 15,
  proficiencyBonus: 2
});

// 2. 生成正文
const context = '你仔细观察周围的环境。';
const output = narrativeSystem.generateCheckNarrative(checkResult, context);

// 3. 显示

```

### 示例 3：手动组装正文
```javascript
const narrative = '你完成了一次探险。';

const tags = {
  exp: narrativeSystem.formatExpTag(25, '完成探索'),
  gold: narrativeSystem.formatGoldTag(20, '出售战利品', 93),
  skill: narrativeSystem.formatSkillTag([
    { name: '锻造', level: 2, type: 'levelup' }
  ])
};

const output = narrativeSystem.formatOutput({ narrative, tags });
```
