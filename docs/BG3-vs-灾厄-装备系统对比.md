## 6️⃣ 耐久系统对比

### BG3
```
❌ 无耐久系统
- 武器永久使用
- 护甲不会损坏
- 不需要修理
```

### 灾厄之后
```javascript
✅ 有耐久系统

武器耐久：
- 每次攻击：-1
- 大失败（天然1）：-5
- 破损时无法使用

护甲耐久：
- 被攻击：-伤害值
- 破损（<50%）：AC -1
- 报废（0）：无防护

修理：
- 可以修理（花费金钱）
- 可以在铁匠处修理
```

**对比：**
- 灾厄更硬核（生存向）
- BG3 更休闲（不用担心装备损坏）
- 这是**设计选择**，不是缺陷
