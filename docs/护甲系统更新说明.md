## 🎮 主要变化

### 1. AC 计算规则（完全符合 BG3）

**旧系统：**
```
AC = 10 + 护甲AC加成 + 敏捷调整
```

**新系统（BG3 标准）：**
```
无护甲：AC = 10 + 敏捷
轻甲：  AC = 护甲AC + 全敏捷
中甲：  AC = 护甲AC + min(敏捷, +2)
重甲：  AC = 护甲AC + 0
```

## 🎯 实际例子

### 例子 1：轻甲角色（敏捷 16, +3）
```
无护甲：10 + 3 = AC 13
皮甲：  11 + 3 = AC 14
镶钉皮甲：12 + 3 = AC 15
镶钉皮甲 + 盾牌：12 + 3 + 2 = AC 17
```

### 例子 2：中甲角色（敏捷 16, +3）
```
链甲衫：13 + 2 = AC 15（敏捷最多+2）
半身板甲：15 + 2 = AC 17
半身板甲 + 盾牌：15 + 2 + 2 = AC 19
```

### 例子 3：重甲角色（敏捷 10, +0）
```
锁甲：  16 + 0 = AC 16（不加敏捷）
板甲：  18 + 0 = AC 18
板甲 + 盾牌：18 + 0 + 2 = AC 20
```

## 🆕 新特性

### 1. 力量需求
- 锁甲需要力量 13
- 夹板甲/板甲需要力量 15
- 不满足：移动速度 -10 英尺（游戏会提示）

### 2. AC 详细显示
```javascript
{
  total: 17,
  breakdown: {
    base: 12,      // 护甲基础 AC
    armor: 2,      // 护甲加成
    dex: 3,        // 敏捷调整
    shield: 2      // 盾牌加成
  },
  armorType: '轻',
  hasShield: true
}
```

### 3. 材料档位影响
```
一阶（铁）皮甲：AC 11
二阶（精铁）皮甲：AC 12 (+1)
三阶（秘银）皮甲：AC 13 (+2)
灾厄（黑曜铁）皮甲：AC 14 (+3)
```
