## 📋 DND 5E 双持规则

### 核心规则
```
1. 主手攻击（正常动作）
   - 正常伤害骰 + 属性调整值

2. 副手攻击（附赠动作）
   - 正常伤害骰
   - 不加属性调整值（除非有专长）
   - 需要主手武器也是单手武器

3. 武器限制
   - 两把武器都必须是单手近战武器
   - 副手武器必须是"轻型"武器（简化版：允许所有单手武器）
   - 不能双持远程武器
   - 不能双持双手武器
```

### 1. 装备检查
```javascript
// 装备副手武器时检查
- 主手必须有武器 ✅
- 主手不能是双手武器 ✅
- 副手武器必须是单手武器 ✅

```

### 2. 攻击机制
```javascript
// 主手攻击
rollWeaponDamage(attributes, false)
  - 伤害骰 + 材料加成 + 力量调整值

// 副手攻击
rollWeaponDamage(attributes, true)
  - 伤害骰 + 材料加成 + 0（不加属性）
```

### 3. 双持检测
```javascript
isDualWielding()
  - 返回 true/false

getDualWieldInfo()
  - 返回主手/副手武器信息
```

## 🔧 API 使用

### 装备双持武器
```javascript
// 先装备主手
const mainSword = createWeapon('废土短刃', 1);
equipItem(mainSword);

// 再装备副手（会自动检查双持条件）
const offSword = createWeapon('废土匕首', 1);
equipItem(offSword);

// 检查是否双持
if (isDualWielding()) {
  console.log('✓ 正在双持');
}
```

### 双持攻击
```javascript
// 主手攻击（正常伤害）
const mainDamage = rollWeaponDamage(attributes, false);
// 例：1d6 + 1(材料) + 2(力量) = 3-9 伤害

// 副手攻击（不加属性）
const offDamage = rollWeaponDamage(attributes, true);
// 例：1d4 + 0(材料) + 0 = 1-4 伤害

console.log(`主手: ${mainDamage.damage}, 副手: ${offDamage.damage}`);
console.log(`总伤害: ${mainDamage.damage + offDamage.damage}`);
```

## 📊 双持优劣势

### 优势
```
✅ 双倍攻击次数（一回合攻击2次）
✅ 增加总伤害输出
✅ 命中失败时有第二次机会
✅ 灵活战术
```

### 劣势
```
❌ 副手攻击不加属性调整值
❌ 无法使用盾牌（失去 +2 AC）
❌ 两把武器都会损耗耐久
❌ 需要附赠动作（可能与其他能力冲突）
```

## 🎮 实际例子

### 例子 1：双短剑
```javascript
主手：废土短刃 (1d6)
副手：废土短刃 (1d6)
力量：14 (+2)

主手攻击：1d6 + 2 = 3-8 伤害
副手攻击：1d6 + 0 = 1-6 伤害
平均总伤害：(5.5 + 2) + (3.5) = 11 伤害/回合
```

### 例子 2：剑 + 匕首
```javascript
主手：废土长刀 (1d8)
副手：废土匕首 (1d4)
力量：16 (+3)

主手攻击：1d8 + 3 = 4-11 伤害
副手攻击：1d4 + 0 = 1-4 伤害
平均总伤害：(4.5 + 3) + (2.5) = 10 伤害/回合
```

### 例子 3：单手剑 + 盾牌（对比）
```javascript
主手：废土长刀 (1d8)
副手：废铁盾牌 (+2 AC)
力量：16 (+3)

主手攻击：1d8 + 3 = 4-11 伤害
防御：AC +2
平均伤害：7.5 伤害/回合（但 AC 更高）
```

---

## ⚖️ 双持 vs 盾牌

| 维度 | 双持 | 剑+盾 |
|------|------|-------|
| **攻击次数** | 2 次/回合 | 1 次/回合 |
| **平均伤害** | 11（双短剑）| 7.5 |
| **AC** | 10+护甲+敏捷 | 10+护甲+敏捷+2 |
| **风格** | 攻击向 | 防御向 |

**结论：**
- 双持：高伤害，低防御（适合敏捷角色）
- 剑盾：中伤害，高防御（适合坦克角色）

## 🚀 战斗系统集成

### 回合流程
```javascript
// 1. 主手攻击（动作）
const mainHit = performAttack(attributes, false);
if (mainHit.hit) {
  const mainDamage = rollWeaponDamage(attributes, false);
  applyDamage(target, mainDamage.damage);
}

// 2. 副手攻击（附赠动作，如果双持）
if (isDualWielding()) {
  const offHit = performAttack(attributes, true);
  if (offHit.hit) {
    const offDamage = rollWeaponDamage(attributes, true);
    applyDamage(target, offDamage.damage);
  }
}
```
