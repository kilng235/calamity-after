## 📋 需求分析

### 核心战斗循环
```
1. 战斗开始
   - 生成敌人
   - 先攻检定（玩家 vs 敌人）
   - 确定行动顺序

2. 回合流程
   - 当前行动者回合
   - 选择行动（攻击/防御/物品/逃跑）
   - 执行行动
   - 检查战斗是否结束

3. 战斗结束
   - 胜利：获得经验+战利品
   - 失败：死亡/逃跑
   - 装备耐久损耗
```

## 🏗️ 系统架构

### 战斗状态机
```
[待命] → [战斗中] → [结束]
   ↑         ↓
   └─────────┘
   （逃跑/死亡）
```

### 回合流程
```
先攻检定
   ↓
玩家回合
   ├─ 选择行动
   ├─ 执行攻击
   └─ 检查胜利
   ↓
敌人回合
   ├─ AI选择行动
   ├─ 执行攻击
   └─ 检查失败
   ↓
下一回合
```

## 🎮 战斗流程详解

### Phase 1: 战斗开始
```javascript
// 1. 创建战斗实例
const combat = startCombat(player, ['灰烬狼', '灰烬狼']);

// 2. 先攻检定
rollInitiative(combat);
// 玩家: d20 + 敏捷调整值
// 敌人: d20 + 敏捷调整值（简化为固定值）

// 3. 确定行动顺序
// turnOrder = ['player', 'enemy_1', 'enemy_2']
```

### Phase 2: 回合循环
```javascript
while (combat.status === 'active') {
  // 获取当前行动者
  const actor = getCurrentActor(combat);
  
  if (actor === 'player') {
    // 玩家回合（等待玩家输入）
    // playerAttack() 或 playerDefend() 或 useItem() 或 flee()
  } else {
    // 敌人回合（AI自动执行）
    enemyTurn(combat, actor);
  }
  
  // 检查战斗结束
  if (checkCombatEnd(combat)) break;
  
  // 下一个行动者
  nextTurn(combat);
}
```

### Phase 3: 战斗结束
```javascript
// 胜利
if (combat.status === 'victory') {
  const rewards = calculateRewards(combat);
  // 发放经验、金币、战利品
}

// 失败
if (combat.status === 'defeat') {
  // 死亡处理
}
```

## ⚔️ 攻击流程（DND 5E）

### 命中检定
```javascript
// 1. 掷骰
attackRoll = d20 + proficiencyBonus + abilityMod + weaponBonus

// 2. 判定
if (attackRoll >= targetAC || attackRoll === 20) {
  hit = true;
}

// 3. 重击
if (attackRoll === 20) {
  criticalHit = true;
  damage *= 2;
}
```

### 伤害计算
```javascript
// 主手攻击
damage = weaponDice + materialBonus + abilityMod

// 副手攻击（双持）
damage = weaponDice + materialBonus + 0  // 不加属性
```

### 双持攻击
```javascript
// 主手攻击（动作）
const mainResult = rollWeaponDamage(attributes, false);

// 副手攻击（附赠动作）
if (isDualWielding()) {
  const offResult = rollWeaponDamage(attributes, true);
  totalDamage = mainResult.damage + offResult.damage;
}
```

creatureAttack(creature, target.ac);

// 狼群战术：头狼存活时获优势

## 🎯 特殊机制

### 装备耐久损耗
```javascript
// 每次攻击
damageWeaponDurability(false, useOffHand);

// 大失败（天然1）
if (roll === 1) {
  damageWeaponDurability(true, useOffHand);
}

// 受到攻击
damageArmorDurability(damage);
```

### 条件状态（可选）
```javascript
conditions: [
  { type: 'poisoned', duration: 3, effect: '攻击劣势' },
  { type: 'feared', duration: 2, effect: '无法接近敌人' },
  { type: 'bleeding', duration: 5, effect: '每回合-2 HP' }
]
```

### 逃跑机制
```javascript
// 逃跑检定
escapeCheck = d20 + 敏捷调整值 vs DC 12

// 成功：逃离战斗（不获得奖励）
// 失败：敌人获得机会攻击
```
