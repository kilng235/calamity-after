# 双持伤害说明

> 为什么副手伤害看起来这么低？

---

## 📊 DND 5E 双持规则（真实规则）

### 核心规则
```
主手攻击（动作）
  伤害 = 武器骰 + 属性调整值
  例：1d6 + 2 = 3-8 伤害

副手攻击（附赠动作）
  伤害 = 武器骰 + 0（不加属性）⚠️
  例：1d4 + 0 = 1-4 伤害
```

**这是 DND 5E 的标准规则！** 副手攻击确实不加属性调整值。

---

## 🎮 实际例子

### 你测试的情况（力量 14, +2）

**主手：铁废土短刃 (1d6)**
```
伤害 = 1d6 + 0(材料) + 2(力量)
范围 = 3-8
平均 = 5.5
```

**副手：铁废土匕首 (1d4)**
```
伤害 = 1d4 + 0(材料) + 0(副手不加属性) ⚠️
范围 = 1-4
平均 = 2.5
```

**总伤害：4-12，平均 8**

---

## 💡 为什么副手不加属性？

### DND 5E 的设计理念

1. **平衡性**
   - 双持给你 2 次攻击机会
   - 如果副手也加属性，伤害会过高
   
2. **动作经济**
   - 主手攻击是"动作"
   - 副手攻击是"附赠动作"
   - 附赠动作应该比动作弱

3. **专长系统**
   - 可以通过"双武器战斗"专长
   - 让副手攻击也加属性调整值
   - 作为角色成长的奖励

## 📈 双持 vs 单手 vs 盾牌对比

### 假设：力量 14 (+2)

| 装备 | 攻击次数 | 总伤害 | AC加成 |
|------|---------|-------|--------|
| **双持** | 2次 | 8 平均 | +0 |
| **剑+盾** | 1次 | 5.5 平均 | +2 AC |
| **双手剑** | 1次 | 7.5 平均 | +0 |

**结论：**
- 双持：最高伤害（8），但 AC 低
- 剑盾：中等伤害（5.5），AC 最高
- 双手：高单次伤害（7.5），平衡

---

## 🔥 双持的真正优势

### 1. 命中机会
```
主手未命中 → 副手还有机会
命中概率提升！
```

### 2. 触发效果
```
某些装备有"命中时触发"效果
双持 = 2 次触发机会
```

### 3. 战术灵活性
```
主手高伤害武器（1d8）
副手快速武器（1d4）
不同武器类型的组合
```

---

## ⚖️ 这合理吗？

### 是的！这完全符合 DND 5E 规则

**博德之门3 也是这样：**
```
主手：长剑 1d8+3 = 4-11 伤害
副手：匕首 1d4+0 = 1-4 伤害（不加属性）
```

**辐射4/上古卷轴5：**
```
双持每只手 50% 伤害
灾厄更慷慨：主手 100%，副手仍有伤害骰
```

## 🎯 如何提升双持伤害？

### 1. 提升力量/敏捷
```
力量 14 (+2) → 力量 16 (+3)
主手伤害 +1
```

### 2. 使用更高材料
```
一阶武器：1d6+0
二阶武器：1d6+1
三阶武器：1d8+1（升档）
灾厄武器：1d8+2
```

### 3. 选择更大骰子的武器
```
副手用 1d6 短剑代替 1d4 匕首
副手伤害 1-4 → 1-6
```

### 4. 未来专长（扩展）
```
"双武器战斗大师"专长
效果：副手攻击也加属性调整值
```
