# 灾厄废土世界观 - 适合的装备清单

> 筛选标准：符合废土/后启示录主题  
> 排除：中世纪奇幻、魔法、过于花哨的装备  
> 整理时间：2026-09-02

---

## 🎯 筛选原则

### ✅ 适合废土世界观
```
- 实用主义：简单、粗暴、有效
- 拾荒改造：废墟中能找到的材料
- 生存工具：刀、斧、锤、弓
- 废土风格：破旧、生锈、拼凑
```

### ❌ 不适合废土世界观
```
- 中世纪骑士装备（细剑/长枪/戟）
- 华丽装饰性武器
- 礼仪性武器（长鞭/网）
- 过于原始的武器（投石索/吹箭筒）
```

### 重甲（4 种）- 部分适合 ⚠️

| 护甲 | AC | 废土改造版本 | 世界观契合度 | 建议 |
|------|-----|-------------|-------------|------|
| **环甲** | 14 | 废铁环甲 | ⭐⭐⭐ | 保留 |
| **锁甲** | 16 | 拾荒锁甲 | ⭐⭐⭐ | 保留 |
| **夹板甲** | 17 | 废铁夹板护甲 | ⭐⭐ | 可选 |
| **板甲** | 18 | 完整板甲 | ⭐ | **不推荐** |

**分析：**
- 环甲/锁甲：可以是旧世界遗留，勉强合理
- 夹板甲：太复杂，废土难以制作
- 板甲：典型骑士装备，**完全不符合废土**

**建议改造：**
```
板甲 → 废土重甲
  - 改名："拼装重甲"/"废铁全身甲"
  - 外观：废铁板拼接，焊痕密布，锈迹斑斑
  - 保持 AC 18，但看起来像废土风格
```
