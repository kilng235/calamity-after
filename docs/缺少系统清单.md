## 🔧 技术备注

### 系统文件接入世界书
新开发的系统文件需要：
1. 导出模板数据（如 `SPELL_TEMPLATES`、`SKILL_TEMPLATES`）
2. 在 `index.html` / `game.html` 里导入
3. 用 `buildXxxWorldbook()` 函数转换为世界书格式
4. 合并到 `mergedWorld` 里注册到 `calamityData`

### 命名规范
- 系统文件名：`xxx-system.js`（如 `status-system.js`）
- 数据常量：`XXX_TEMPLATES`（如 `SPELL_TEMPLATES`）
- 世界书分类：`"xxx"`（如 `"法术"`、`"技能"`）
- 避免与世界书原有"总纲"条目冲突，改用"数据清单"命名
