# BG3 生物参考

## 🎮 BG3 经典低级生物

### 1. 地精（Goblin）
```
CR: 1/4
HP: 7 (2d6)
AC: 15 (皮甲+盾牌)
攻击: +4，伤害 1d6+2 (弯刀)
特性: 灵巧逃脱（脱离不引发机会攻击）
```

**灾厄改造：废土掠夺者**
```yaml
威胁等级：低
HP: 12 | AC: 13 | 伤害 1d6
特性：
  - 群体战术：同伴在5英尺内时攻击获优势
  - 懦夫：受到重伤时可能逃跑
战利品：
  - 废铁武器、破布
```

---

### 2. 僵尸（Zombie）
```
CR: 1/4
HP: 22 (3d8+3)
AC: 8
攻击: +3，伤害 1d6+1 (猛击)
特性: 不死韧性（HP降至0时，DC 5+伤害，成功则保留1HP）
```

**灾厄改造：感染者**
```yaml
威胁等级：中
HP: 24 | AC: 10 | 伤害 1d8
特性：
  - 不死韧性：首次HP归0时50%概率保留1HP
  - 感染撕咬：命中后目标需体质豁免（DC12），失败中毒
战利品：
  - 灾厄结晶、破损装备
```

---

### 3. 骷髅（Skeleton）
```
CR: 1/4
HP: 13 (2d8+4)
AC: 13 (碎甲)
攻击: +4，伤害 1d6+2 (短弓) 或 1d6+2 (短剑)
弱点: 钝击伤害易伤
```

**灾厄改造：白骨行者**
```yaml
威胁等级：低
HP: 12 | AC: 12 | 伤害 1d6
特性：
  - 骨架脆弱：受到钝击伤害时额外+2伤害
  - 远程射击：可使用弓箭远程攻击
战利品：
  - 古老骨骸、破损武器
```

### 4. 巨蜘蛛（Giant Spider）
```
CR: 1
HP: 26 (4d10+4)
AC: 14 (天生护甲)
攻击: +5，伤害 1d8+3 + 毒素（2d8毒伤，体质DC11）
特性: 蛛网行走、蛛网感知
```

**灾厄改造：灰烬蛛**
```yaml
威胁等级：中
HP: 24 | AC: 13 | 伤害 1d8
特性：
  - 毒刺：命中后目标需体质豁免（DC12），失败额外1d6毒伤
  - 结网：可以释放蛛网困住目标（力量DC13挣脱）
战利品：
  - 蛛网丝、毒腺
```

**灾厄改造：嗜血掠食者**

```yaml
威胁等级：中

  - 嗜血撕咬：HP低于50%时攻击获优势

  - 掠食者毛皮、尖牙
```

```
AC: 14 (天生护甲)
攻击: +6，伤害 2d8+4 (巨斧) 或 2d8+4 (冲撞)
特性: 狂怒冲锋（冲锋后可推倒目标）
```

**灾厄改造：废土巨兽**
```yaml
威胁等级：高
HP: 48 | AC: 15 | 伤害 1d12
特性：
  - 狂暴冲撞：冲锋攻击命中后目标需力量豁免（DC14），失败击倒

```

```
特性: 虚体（非魔法伤害抗性）、阳光敏感
```

**灾厄改造：灾厄幽灵**
```yaml
威胁等级：高
HP: 48 | AC: 13 | 伤害 1d12
特性：
  - 虚体：物理伤害减半
```

### 10. 巨魔（Troll）
```
CR: 5
HP: 84 (8d10+40)
AC: 15 (天生护甲)
攻击: +7，伤害 1d6+4 (爪×2) + 1d6+4 (咬)
特性: 再生（每回合恢复10HP，火焰/强酸阻止）
```

**灾厄改造：再生魔物**
```yaml
威胁等级：高
HP: 48 | AC: 14 | 伤害 1d12
特性：
  - 快速再生：每回合恢复5HP
  - 弱点火焰：受到火焰伤害的回合无法再生
  - 多重攻击：可以进行两次攻击
战利品：
  - 再生组织、魔物血液
```

## 🎨 废土风格命名原则

### BG3 → 灾厄改造
```
地精 → 废土掠夺者
僵尸 → 感染者
骷髅 → 白骨行者
巨蜘蛛 → 灰烬蛛
豺狼人 → 嗜血掠食者
牛头人 → 废土巨兽
幽魂 → 灾厄幽灵
食人魔 → 废土暴徒
年轻绿龙 → 灾厄龙蜥
巨魔 → 再生魔物
```

**风格特点：**
- ✅ 去除奇幻元素（地精→掠夺者）
- ✅ 强调废土主题（废土XX）
- ✅ 保留核心特性（再生→再生魔物）
- ✅ 符合灾厄世界观（灾厄XX）
