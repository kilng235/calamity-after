## 二、 近期重点优化与修复归档（2026-09-14 批次）

本周期通过后台多代理深度审查与多轮迭代，完成了 **4 次核心提交**：

1. **`69beb16` fix(core): 核心业务与数值契约收敛**
   - 修复炼金系统杰出品级（gradeBonus=2）在强效药水上的爬升分支漏判（告别品质收益倒挂）。
   - 修复治疗药水在 `hp.max` 未明确定义时的取值短路 Bug（彻底解决喝药不回血问题）。
   - 为背包增加了自愈初始化防御（`Array.isArray` 防护），杜绝产出丢失与运行时 TypeError。
   - 修复开局核心场景数据缓存丢失 Bug（`this.openingData` 正式落盘）。
   - 废弃 `game-state.js` 内旧版乘算升级逻辑，全面收敛由 `commandProcessor.syncLevel` 契约查表驱动。

2. **`96d6755` fix(ai): AI 链路网络韧性与长线续航保障**
   - 流式请求（SSE）引入超时心跳熔断，异常或静默挂起时自动释放，防止界面永久冻结。
   - 修复普通请求定时器句柄泄漏（`clearTimeout`），释放后台无用计时器。
   - NPC 主观记忆提取接入 `safeParseLLMJson` 容错修复器，大幅提升格式容错与记忆召回率。
   - 提示词组装引入最近 20 条（10 轮）滑动截断窗口，根除长线游玩的 `400 Context Length Exceeded` 报错。

3. **`d478fd3` fix(arch): 状态持久化安全与架构规范**
   - 变量系统引入深拷贝快照与导出导入机制，确保回合回滚（Undo）完全可逆。
   - 实现纯 AST 递归下降四则算术解析器，彻底移除 `new Function` 动态求值。
   - 任务系统扩展双向数据同步转换（`syncToGameData` / `syncFromGameData`），消除数据容器双轨制。

4. **`5e25380` & `862e322` fix(ui & asset): 交互体验升级与视觉资源恢复**
   - 修复中文输入法（IME）按 Enter 选词时误发未完成拼音的问题。
   - 修复角色登记册路由 ID 错位（`create-p1` → `p1`）。
   - 输入框禁用策略由 `disabled` 改为 `readOnly`，消除移动端软键盘弹跳抖动。
   - 长篇剧情正文增加智能贴底滚动判定（向上翻看历史记录时不被打断）。
   - 优化 `variable-ui.js` 脏检查机制，消除大对象序列化卡顿。
   - 完整恢复主界面封面断剑插画资源（`cover-02-broken-sword.png`）。
